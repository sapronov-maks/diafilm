# Diafilm — политика конфиденциальности

Действует с 11 ноября 2026 года. Относится к приложению Diafilm для Android (телефоны, планшеты, телевизоры).
Разработчик: Sapronov. Связь: **diafilm@tacthub.net**.

## Коротко

Diafilm **не собирает, не хранит у себя и не передаёт персональные данные**. В приложении нет рекламы, аналитики,
счётчиков и регистрации. Приложение не передаёт никому идентификаторов устройства или пользователя.

## Что хранится на устройстве

- Картинки, избранное, настройки и журнал событий хранятся только на вашем устройстве. Удалите приложение — удалятся и они.
- Резервное копирование данных приложения в облако выключено.
- Ключи сервисов (если вы их вводите) хранятся только на устройстве.
- Журнал событий никуда не отправляется сам. Его можно отправить вручную кнопкой «Отправить» — тогда вы сами выбираете, кому.
- Файл переноса настроек вы создаёте сами и сами решаете, куда его положить. Ключей сервисов, избранного и папки «Свои фото» в нём нет.

## С кем приложение связывается по сети

**Сервисы картинок.** Чтобы показывать картинки, приложение обращается к открытым сервисам: Bing и Windows Spotlight
(Microsoft), Wikimedia Commons, NASA, музеи (The Met, Эрмитаж, Кливленд, SMK, V&A, Художественный институт Чикаго), Wallhaven,
а если вы ввели ключ — Unsplash и Pexels. Как любой сайт, эти сервисы видят ваш IP-адрес и запрос (например, тему картинок),
но не получают от приложения никаких данных о вас. У каждого сервиса своя политика.

**«Своя тема».** Слова, которые вы пишете для своей темы, отправляются сервисам картинок как поисковый запрос. Слова на
русском перед этим переводятся на английский через Google Переводчик, а если он недоступен — через Википедию: им передаётся
только само слово.

**Сервер проекта.** Часть картинок идёт через сервер проекта (img.tacthub.net): он уменьшает большие картинки под экран
и помогает, когда сервис картинок недоступен напрямую, — тогда запрос к сервису (для Unsplash — вместе с вашим ключом)
проходит через него. Сервер ничего из этого не сохраняет, кроме временных копий картинок, и не ведёт журнал обращений.
Если он не отвечает, картинка может уменьшаться через открытый сервис wsrv.nl — ему передаётся только адрес картинки.

**Обновления.** Версия с GitHub проверяет обновления на github.com (список выпусков открытого репозитория). Версии из
магазинов приложений обновляются через магазин и сами обновления не проверяют.

**Ссылки.** «Поддержать проект», «Открыть страницу» у картины и сайт проекта открываются в браузере — дальше действуют
правила этих сайтов (CloudTips, Boosty, сайт музея или сервиса). Само приложение платежи не принимает и ничего о них не знает.

## Разрешения

- Интернет и состояние сети — чтобы скачивать картинки и не тратить мобильный трафик без надобности.
- Обои — чтобы ставить картинки на рабочий стол и экран блокировки.
- Не давать устройству заснуть — ненадолго, пока меняется картинка на экране блокировки или докачиваются новые.
- Уведомления — только в версии с GitHub и только если вы включили «Сообщать о новой версии». Версии из магазинов
  уведомлений не показывают.
- «Поверх других приложений» — только если вы включили фоторамку на зарядке.
- Установка приложений — только в версии с GitHub, чтобы ставить обновления. В версиях из магазинов этого разрешения нет.
- Доступ к папке — только к той, которую вы сами выбрали для «Своих фото».

## Обратная связь

Письмо из приложения (Настройки → Приложение → «Написать отзыв») уходит с вашей почты; в нём только то, что вы написали,
плюс версия приложения, модель устройства и версия Android — чтобы было проще разобраться с ошибкой.

Вопросы и отзывы: **diafilm@tacthub.net**.

# Diafilm — Privacy Policy (English)

Effective 11 November 2026. Applies to the Diafilm app for Android (phones, tablets, TVs).
Developer: Sapronov. Contact: **diafilm@tacthub.net**.

## In short

Diafilm **does not collect, store or share personal data**. The app has no ads, analytics, trackers or accounts.
It does not send device or user identifiers to anyone.

## What is stored on your device

- Pictures, favorites, settings and the event log are stored only on your device. Uninstall the app and they are gone.
- Cloud backup of the app's data is turned off.
- Service keys (if you enter any) are stored only on your device.
- The event log is never sent automatically. You can send it manually with the “Send” button — you choose the recipient.
- The settings transfer file is created by you, and you decide where to keep it. It contains no service keys, favorites
  or “My photos” folder.

## Who the app talks to over the network

**Image services.** To show pictures, the app requests open services: Bing and Windows Spotlight (Microsoft), Wikimedia
Commons, NASA, museums (The Met, the Hermitage, the Cleveland Museum of Art, SMK, the V&A, the Art Institute of Chicago),
Wallhaven and, if you entered a key, Unsplash and Pexels. Like any website, these services see your IP address and the
request (for example, the picture topic), but they receive no data about you from the app. Each service has its own policy.

**“Custom theme”.** The words you type for your own theme are sent to image services as a search query. Words in Russian
are first translated into English with Google Translate or, if it is unavailable, with Wikipedia: only the word itself is sent.

**Project server.** Some pictures go through the project server (img.tacthub.net): it downsizes large pictures to fit the
screen and helps when an image service cannot be reached directly — then the request to that service (for Unsplash,
together with your key) passes through it. The server stores none of this except temporary copies of pictures, and it
keeps no access log. If it does not respond, a picture may be resized by the open service wsrv.nl, which receives only
the picture's address.

**Updates.** The GitHub version checks github.com for updates (the list of releases of the public repository). Versions
from app stores are updated by the store and do not check for updates themselves.

**Links.** “Support the project”, “Open webpage” for a picture and the project website open in your browser — from there
the rules of those sites apply (CloudTips, Boosty, the website of a museum or service). The app itself does not accept
payments and knows nothing about them.

## Permissions

- Internet and network state — to download pictures and not waste mobile data.
- Wallpaper — to set pictures on the home screen and the lock screen.
- Prevent the device from sleeping — briefly, while the lock screen picture is changing or new pictures are downloading.
- Notifications — only in the GitHub version and only if you turned on “Notify about new versions”. Store versions show
  no notifications.
- “Display over other apps” — only if you turned on the photo frame while charging.
- Install apps — only in the GitHub version, to install updates. Store versions do not have this permission.
- Folder access — only to the folder you chose yourself for “My photos”.

## Feedback

An email from the app (Settings → App → “Send feedback”) is sent from your own mailbox; it contains only what you wrote,
plus the app version, device model and Android version — to make it easier to find the problem.

Questions and feedback: **diafilm@tacthub.net**.
